Official Planar Standard events are run by the organising group's tournament
organisers. These notes are for them.

## Export results the same day

**melee.gg deletes tournament data after about 60 days.** After that the event
cannot be imported or rated. Export as soon as the last round is done.

## Before the event

- Announce the pool if it differs from the standard six sets.
- Collect decklists at registration.

## Ratings

Only **Monthly** events are rated, and only if the export includes pairings.
Standings-only events still count for the metagame. Byes never move a rating.

## Submitting

Upload the export exactly as the platform produced it, without editing it.
Accepted: melee.gg export, Challonge export, or a CSV of pairings and results.
Decklists are optional and never block a result.

Re-importing an event replaces the previous import completely.

## Handles

Record the handle each player used. Linking handles to players is done
separately.
